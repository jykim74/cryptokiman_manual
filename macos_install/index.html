    Install BerEditor on macOS

    1. Open the downloaded BerEditor disk image (.dmg). A window like the one below will appear.

    1. Click and hold the BerEditor icon.
    2. Drag it onto the Applications folder icon, then release the mouse button.
    3. Wait for the copy to finish, then eject the BerEditor disk image.
    4. Open Applications and double-click BerEditor to launch it.

    If macOS asks you to confirm that you want to open the app, review the prompt and choose Open.
